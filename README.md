# Glimsy — Influencer Fashion Marketplace

A soft, minimal website concept for a **women-focused fashion marketplace** where influencers can:

- sell their own products,
- list preloved items,
- recommend affiliate products,
- share OOTD photos and reels,
- and let users follow, browse, and purchase directly.

## Full Site Flow

| Page | Purpose | Key Experience |
| --- | --- | --- |
| `index.html` | Homepage | Introduces the brand, key style moods, featured influencers, and the shopping journey |
| `influencer.html` | Influencer profile | Social-media-style profile with photo looks, reels, follow button, and clickable outfit cards |
| `product.html` | Single product page | Product details, fashion story, category, price, and add-to-cart action |
| `cart.html` | Add to cart page | Review items before payment and continue shopping |
| `checkout.html` | Checkout page | Enter customer details, shipping, payment method, and confirm order |
| `thank-you.html` | Thank you page | Order confirmation after successful purchase |

## Website Direction

### Brand feel
- **Soft, minimal, feminine**
- Social-media-inspired, but still clearly ecommerce
- Easy navigation for browsing, following, and buying

### Fashion niche focus
For the first version, the marketplace is focused only on:
- tops
- bottoms
- skirts
- scarves
- light fashion accessories

### Core user journey
1. User lands on the homepage.
2. User discovers a favourite influencer.
3. User opens the influencer profile and sees photo posts + reels.
4. User clicks an outfit image.
5. User arrives on the product detail page.
6. User adds the item to cart.
7. User proceeds through checkout.
8. User reaches the thank-you page.
